# printed_output

stdout example for C17 and C++17 student answers.

Implement `print_message()` so it prints exactly `hello world` followed by a newline.

* `template.cpp`: unfinished student template, valid in either answer language.
* `test_answer.cpp`: teacher Catch2 tests, always compiled as C++17.
* `answer.cpp`: a possible solution, valid in either answer language.

The guarded `main` runs the program manually; Catch2 uses its own `main`.
See [the C/C++ examples guide](../README.md) for setup and scoring.
