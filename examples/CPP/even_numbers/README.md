# even_numbers

Return even integers, preserving their order and duplicates.

C uses `even_numbers(values, count, output)` and returns the number written.
The caller provides an output array with space for `count` integers.
C++ uses `even_numbers(const std::vector<int>&)` and returns a vector.

- C: [template](template.c), [solution](answer.c).
- C++: [template](template.cpp), [solution](answer.cpp).
- [Catch2 tests](test_answer.cpp): mixed values, empty input, and no matches.
