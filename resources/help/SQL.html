SQL - Plugin

SQL-Aufgaben erstellen, ausprobieren und mit Python-UnitTests bewerten.

Beispiele

Im Tab UnitTest ein Beispiel auswählen und mit Apply laden: SELECT, INSERT, UPDATE, DELETE oder JOIN. Vorhandener Code wird nach Rückfrage ersetzt.

Kurz erklärt

Preparation: Tabellen und Daten mit SQL anlegen. Jeder Lauf beginnt mit einer neuen SQLite-Datenbank.
Template: SQL-Vorlage für Studierende.
UnitTest: Python-Tests in Checker(unittest.TestCase); zuvor import unittest und import answer.

Prüfen und bewerten

answer.rows und answer.columns: letztes Abfrageergebnis.
answer.results: alle Ergebnisse mit rows und columns.
answer.connection.execute(...): Datenbank prüfen.
answer.reset() in setUp: Datenbank je Test zurücksetzen.

Run SQL: Template ausführen.
Format: Aktiven Tab formatieren: SQL mit sqlparse, UnitTests mit Ruff. Rückgängig im Editor ist möglich.
Check tests / Calculate score: Tests ausführen; jeder Test zählt gleich viel. SQL-Fehler ergeben keine Punkte.

Configuration

CPU-Zeit für den gesamten Lauf und den Run-Button der Studierenden festlegen. Für feste Zeilenreihenfolge ORDER BY verwenden.

Der Tab zeigt auch Datensatzvariablen mit Name, Wert und Einheit. In UnitTests: from dataset import DATASET_VARIABLES, dann DATASET_VARIABLES["name"].value oder .unit. Python-Bezeichner lassen sich direkt importieren, z. B. from dataset import n.
