Python - Plugin

Mit diesem Plugin können Python-Aufgaben erstellt, ausprobiert und automatisch bewertet werden.

Kurz erklärt

  • UnitTest: Enthält die Tests, mit denen die eingereichte Lösung geprüft wird.
  • Preview: Enthält den Python-Code für die Vorschau beziehungsweise Musterlösung.
  • Files: Hier lassen sich zusätzliche Dateien hochladen, herunterladen und löschen.

Configuration

  • run at test: Führt beim Testen die UnitTests gegen die abgegebene Lösung aus.
  • lint at test: Prüft beim Testen zusätzlich die Codequalität mit dem Linter.
  • Linter configuration: Hier können zusätzliche Linter-Optionen angegeben werden, beispielsweise Regeln, die nicht geprüft werden sollen.
  • Weight: Legt fest, wie stark das Linter-Ergebnis im Verhältnis zum UnitTest-Ergebnis in die Gesamtpunkte eingeht.
  • Dataset variables: Zeigt die verfügbaren Aufgabenvariablen mit Wert und Einheit. Im UnitTest können sie aus dataset importiert werden.

Buttons

  • run: Führt den Code des aktuell geöffneten Editors aus und zeigt dessen Ausgabe an.
  • lint: Prüft den Stil des Codes im aktuell geöffneten Editor anhand der Linter-Konfiguration.
  • check: Führt die UnitTests mit dem Preview-Code aus und zeigt das Prüfergebnis an.
  • score: Berechnet die Punkte aus UnitTests und – sofern aktiviert – dem gewichteten Linter-Ergebnis.

Beispiele verwenden

Wählen Sie im Bereich UnitTest ein Beispiel aus und klicken Sie auf Apply. Würde dabei eigener Code ersetzt, erscheint vorher eine Warnung. Mit Ja, überschreiben übernehmen Sie das Beispiel; mit Nein bleibt Ihr Code unverändert.
