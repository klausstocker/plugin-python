Python - Plugin

Mit diesem Plugin können Python-Aufgaben erstellt, ausprobiert und automatisch bewertet werden.

Kurz erklärt

  • UnitTest: Enthält die UnitTests, mit denen die eingereichte Lösung geprüft wird.
  • Preview: Enthält den Python-Code für die Angabe bzw. Musterlösung.
  • Files: Hier lassen sich zusätzliche Dateien verwalten.

Configuration

  • run at test: Lässt "run" im Rahmen eines Tests zu.
  • lint at test: Lässt "lint" im Rahmen eines Tests zu.
  • Linter configuration: Hier können zusätzliche Linter-Optionen angegeben werden, beispielsweise Regeln, die nicht geprüft werden sollen.
  • Weight: Legt fest, wie stark das Linter-Ergebnis im Verhältnis zum UnitTest-Ergebnis (1.0) in die Gesamtpunkte eingeht.
  • Dataset variables: Zeigt die verfügbaren Aufgabenvariablen mit Wert und Einheit. Im UnitTest können sie aus dataset importiert werden.

Hilfsmodul helpers.py

Das Modul helpers.py stellt Hilfsklassen für UnitTests bereit: helpers.py ansehen oder herunterladen.

  • RedirectedStdout: Fängt innerhalb eines with-Blocks die Standardausgabe (z. B. print) auf. str(ausgabe) liefert den aufgefangenen Text. Beim Verlassen des Blocks wird die ursprüngliche Standardausgabe wiederhergestellt, auch bei Fehlern.

Zum lokalen Testen die Datei neben test_answer.py speichern.

Buttons

  • run: Führt den Code des aktuell geöffneten Editors aus und zeigt dessen Ausgabe an.
  • lint: Prüft den Stil des Codes im aktuell geöffneten Editor anhand der Linter-Konfiguration.
  • check: Führt die UnitTests mit dem Preview-Code aus und zeigt das Prüfergebnis an.
  • score: Berechnet die Punkte aus UnitTests und – sofern aktiviert – dem gewichteten Linter-Ergebnis.
